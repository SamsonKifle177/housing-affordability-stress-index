# Global Housing Affordability Stress Index

## Overview

This project analyzes housing affordability pressure across countries using public housing, macroeconomic, and population datasets.

The goal is to identify which countries are experiencing the highest housing affordability stress, what factors are associated with that stress, and which markets may require closer monitoring.

## Business Problem

Housing affordability is a growing concern across many countries. House prices, rents, income growth, inflation, and urban population growth all affect whether households can access affordable housing.

This project builds a country-level Housing Affordability Stress Index using public data from OECD and World Bank sources.

## Main Questions

1. Which countries have the highest housing affordability stress?
2. Which countries have seen affordability deteriorate fastest?
3. Are house prices rising faster than incomes?
4. Is urban population growth associated with housing affordability pressure?
5. Which countries should policymakers and analysts monitor most closely?
